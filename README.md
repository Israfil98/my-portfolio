# Israfil Guseinov — Portfolio

Personal developer portfolio built with React, TypeScript, Tailwind CSS, and Framer Motion.

**Live:** [my-portfolio-bice-six-28.vercel.app](https://my-portfolio-bice-six-28.vercel.app)

## Tech Stack

- React 19 + TypeScript + Vite 7
- Tailwind CSS 4
- Framer Motion
- React Hook Form
- ESLint + Prettier + Husky + lint-staged

## Run Locally

```bash
git clone https://github.com/Israfil98/my-portfolio.git
cd my-portfolio
npm install
npm run dev
```
